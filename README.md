# SEKOLA

**Semua Urusan Sekolah, Satu Platform.** · One Platform. Every School.

Desain produk SEKOLA, platform manajemen sekolah multi-tenant: Platform Console, School Workspace, dan aplikasi mobile untuk siswa, orang tua, guru, dan wali kelas.

## Isi repositori

| Folder | Isi |
| --- | --- |
| `design/` | Kanvas desain: 42 artboard `.dc.html` + `canvas.json` (identitas merek, design tokens, komponen, console, workspace, mobile, status layar) |
| `presentasi/` | Slide presentasi penawaran: 12 slide (`slides/*.html`) + `deck.json` |

## Status

Ini adalah **prototipe desain**. Semua interaksi disimulasikan; belum ada backend, autentikasi, pembayaran, integrasi WhatsApp, Dapodik, atau SSO yang berjalan. Semua nama sekolah, orang, dan angka adalah data fiktif untuk demonstrasi.

Logo dan nama SEKOLA masih konsep awal; ketersediaan merek dagang belum dicek.
